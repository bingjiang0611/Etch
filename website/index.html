Why Etch

生成字幕不难。
难的是每句都经得起检查。

视频译制最怕的不是慢，而是同一个专有名词前后变译法、错误藏在数百条字幕里，以及失败后整条流水线重来。Etch 把质量控制放进生成过程本身。

术语跨批次一致

集中审计专业术语和歧义译法，回到对应字幕逐条确认。长视频被分成多少批，都不该失去同一套语言。

逐句双语校对

英文原句、中文译文、时间码并排呈现。修改自动保存，确认后再压制，不把“AI 已生成”误当成“已经可发布”。

任务失败可恢复

下载、转写、翻译、审计和压制都有明确产物。某一步失败或字幕被修改，只重跑真正受影响的阶段。

FAQ

构建前，你可能想知道。

Etch 会把视频上传到自己的云端吗？

不会。Etch 的下载、转写、文件管理和压制流程运行在你的 Mac 与本地工作区。翻译内容是否离开设备，取决于你所选择的 Agent CLI 及其服务条款。

为什么需要本地 Agent CLI？

Etch 复用你已经安装并登录的 Claude、Codex、Qoder 或 OpenCode CLI 完成长上下文翻译，因此不需要在 Etch 内重复配置模型 API。至少安装其中一个即可。

支持 Intel Mac 吗？

当前 0.1.1 DMG 只面向 Apple Silicon，最低系统版本为 macOS 13.5。

它支持哪些类型的视频？

课程、访谈、演讲、视频播客、纪录片和其他英文视频都可以。Etch 专注双语字幕译制，不提供时间线剪辑、短视频模板或特效工具。

有可公开下载的安装包吗？

有。GitHub Release 提供 Apple Silicon DMG；当前仍是 ad-hoc 签名且未经 Apple 公证，首次启动可能需要在 Finder 中右键打开，或到“系统设置 → 隐私与安全性”选择“仍要打开”。
