Why the name

Etch 是“刻蚀、镌刻”的意思。

Etch /etʃ/。校对完成的中英字幕会被压进视频画面，和成片一起保存。名字直接来自这个动作。

Local-first

下载、转写、文件管理、字幕生成与压制在本机完成；翻译数据是否离开设备取决于你选择的 Agent CLI。

可恢复

异常退出后从 task.json、durable run registry 和阶段产物恢复，不把退出码 0 当作成功证明。

术语一致

新任务参考历史视频术语表；术语修改可先预览影响到的 cue，再一次性应用到全部译文。

Provider 可替换

支持 Claude、Codex、Qoder、OpenCode 本地 CLI，不绑定单一 SDK，也不依赖常驻服务。

人工可控

逐句中英对照、视频定位、自动保存、审核 checkpoint，可重新生成 SRT 与成片。

验证后投稿

Etch v0.1.26 可手动或按模板自动投稿到 B站。凭据由 macOS 安全存储加密，上传由本机直连平台。

验证后 · 可选投稿 sidecar

成片验证通过，
直投 B站。

使用具备投稿权限的 B站账号扫码连接。Etch 只让验证通过的成片进入本地投稿队列；每次提交前，你仍然掌握标题、分区、标签、简介、版权类型、转载来源与封面。

01
手动确认，或默认关闭的自动投稿新建任务时可按需开启；账号、默认分区和标签不完整时不会误启用。
02
凭据由 macOS 安全存储加密投稿时由本机内置 biliup 直连 B站，不经过 Etch 自建云端或中转服务。
03
只有可验证回执才标记成功若提交结果无法确认，Etch 会要求先到创作中心核对，再决定后续动作。
01 · CONNECT扫码连接账号

读取投稿分区，配置默认标签与简介模板。

02 · REVIEW确认投稿信息

URL 任务默认按转载处理，并自动带入来源。

03 · UPLOAD加入本地单并发队列

上传阶段可以停止，之后从 Etch 重新发起投稿。

04 · RECEIPT保存可验证回执

取得 aid、BV 号等回执后，才显示已提交。

V1 边界单账号、单投稿并发；不支持定时、多账号、审核轮询或远端稿件管理。提交成功后，请到 B站创作中心查看审核状态。
