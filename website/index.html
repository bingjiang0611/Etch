把视频和网页，刻成能交付的中文成果。

Etch 是一个跑在你自己 Mac 上的桌面工作站。双语硬字幕、视频总结、网页翻译三类任务共用一条按阶段保存进度的流水线，中断之后从已确认的地方继续。

三类任务

同一个入口，三条不同的流水线。

Etch 在创建任务时分流：视频走字幕或总结，网页走文档处理。三者共享恢复机制，但各自产出不同文件。

01

双语硬字幕

支持 YouTube、Vimeo 和 X / Twitter 的公开视频链接。取不到英文字幕时，使用 mlx_whisper 在本机转写。

  • 按来源选择媒体与字幕获取方式
  • 长字幕分批翻译，每批通过校验后保存
  • 校对后生成双语 SRT，再压制并验证成片

02

视频总结

从字幕生成素材包，核验可外查事实，再让 A / B / C 三个隔离会话分别成稿、评分与融合。

  • 外部核验记录随任务保存；不可用时明确标记限制
  • 候选稿、评分和遗漏清单彼此隔离
  • 配图可以跳过；真实视频与真实 Provider 的完整 L3 尚未执行

images/（可选）

03

网页转 Markdown / 离线 HTML

支持普通网页、单条 X 帖子和 X Article。可以只转 Markdown，也可以选择标准翻译或精校翻译。

  • 静态图片本地化，结构异常时退回校对
  • 长文分批保存；精校模式增加润色与终检
  • 校对后可生成资源内嵌的离线单文件 HTML

公开 v0.2.45 已包含

成片验证通过后，可以直接投稿到 B站。

用有投稿权限的账号扫码连接后，可手动确认投稿信息，也可在新建字幕任务时开启自动投稿。

  1. 01
    投稿前确认标题、分区、标签、简介、版权类型、转载来源与封面都可以检查。
  2. 02
    凭据留在本机账号凭据由 macOS safeStorage 加密，内置 biliup 从本机直连 B站。
  3. 03
    有回执才算成功只有取得 aid、BV 号等可验证回执才标记为已提交；结果不明时先到创作中心核对。
运行环境

启动时，缺什么就显示什么。

Etch 会逐项检查本机工具。网页只转 Markdown 不需要视频工具或 Agent；网页翻译、字幕翻译和视频总结需要至少一个已登录的 Agent CLI。

系统Apple Silicon Mac · macOS 13.5 或更高版本
视频处理yt-dlp · ffmpeg · ffprobe · Python · mlx_whisper
Agent CLIClaude · Codex · Qoder · OpenCode，至少登录一个
输入仅支持 HTTP(S) URL，暂不支持本地文件导入
