Building a reliable web-to-Markdown pipeline

Source: example.com/articles/reliable-markdown

Converting a page is the easy part. Preserving its structure, media, citations, and reading order is the real work.

Clean before translating

A dependable workflow isolates the article body, removes navigation and subscription chrome, then creates a media manifest before translation begins.

Verify every block

Every heading, paragraph, list, code block, and image receives a stable block id. The translated document is complete only when every block aligns with its source.

如何构建可靠的网页转 Markdown 流水线

原文：example.com/articles/reliable-markdown

把网页转换成文本并不难。真正困难的是保留原文结构、媒体、引用与阅读顺序。

先清洗，再翻译

可靠的工作流会先识别正文，移除导航和订阅模块，再建立媒体清单；完成这些步骤后，翻译才会开始。

逐块核验

每个标题、段落、列表、代码块和图片都有稳定的 block id。只有当译文中的每个 block 都与原文对齐，任务才算完成。

原文 block 数 = 12
译文 block 数 = 12
缺失媒体数    = 0
